🟢 貓咪可以吃的(適量、無調味)

當零食或鮮食點綴 OK,但都不能取代主食

🍗
水煮雞胸肉 / 雞肉
無鹽無調味,撕小塊。優質動物蛋白,適口性高
🐟
熟鮭魚 / 鱈魚(去刺)
含 Omega-3,煮熟去刺。偶爾吃,別過量(汞)
🥚
白煮蛋
完整氨基酸,蛋白質黃金標準。少數貓會過敏
🎃
南瓜泥
溫和纖維,對軟便、便祕、毛球都有幫助
🍠
蒸地瓜(少量)
膳食纖維 + β-胡蘿蔔素,GI 比馬鈴薯低
🌿
貓草 / 木天蓼
幫助排毛球、轉移情緒。觀察主子反應,別過量
💧
無調味肉湯 / 寵物用湯包
不愛喝水的貓的補水神器。沒喝完 1-2 小時要丟
🐾 🐾 🐾

🔴 貓咪千萬不能碰(有毒!)

誤食後黃金時間 1-2 小時,別等症狀出現直接聯絡獸醫

🧅
洋蔥 / 大蒜 / 韭菜 / 蔥
有機硫化合物破壞紅血球→溶血。加熱、乾燥都無法解毒
🍇
葡萄 / 葡萄乾
會引發急性腎衰竭,沒有「安全量」
🍫
巧克力 / 可可
可可鹼中毒,越苦越毒。可能心律不整、癲癇
🍬
木糖醇(無糖口香糖、代糖)
嚴重低血糖 + 肝損傷,一片口香糖就危險
🍷
酒精 / 發酵水果
快速進入腦部,中樞神經抑制、昏迷
☕
咖啡 / 茶 / 能量飲
咖啡因中毒,心跳過快、震顫、癲癇。茶包咖啡渣也別亂丟
🥑
酪梨
果肉含 persin + 高油脂,可能嘔吐、胰臟發炎
🥛
牛奶(成貓)
多數成貓乳糖不耐,會腹瀉。要喝請選貓專用羊奶/牛奶
🦴
煮熟的骨頭 / 雞骨
煮熟易碎裂成尖刺,刺傷消化道

😻 扁臉貓星人 特別照護

波斯、加菲、異短、英短摺耳... 扁臉品種要多注意這些

💧 淚痕清潔

扁臉貓淚腺結構容易溢淚,每天用溫和濕紙巾輕擦眼周。飲食單純、無穀低敏可減少溢淚;發紅或大量分泌物請看醫生。

🫁 呼吸道照顧

短鼻品種容易打呼、呼吸聲重。避免太熱太悶的環境,夏天開冷氣;運動後喘很久或張嘴呼吸要警覺。

⚖️ 體重控制

扁臉貓常偏靜、容易胖,胖了又加重呼吸負擔。定量餵食、別放飼料吃到飽,多用逗貓棒玩到喘。

🍽️ 食盆選擇

扁臉貓嘴巴構造特殊,深窄碗不好吃。選寬口淺盤,讓他不用埋頭、鬍鬚不會卡碗壁。
